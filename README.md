CoreSway enables real-time, distributed processing of complex tasks on scalable clusters, optimizing performance across heterogeneous processors and platforms.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/CoreSway.git`
2. `cd CoreSway`
3. Install in editable mode: `pip install -e .`

## Configuration

CoreSway is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
